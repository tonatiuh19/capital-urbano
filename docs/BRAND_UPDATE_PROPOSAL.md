# Propuesta integral de actualización de marca — Capital Urbano

**Documento base:** *Comunicación — Capital Urbano Presentación* (29 pp.)  
**Alcance:** sitio público, panel admin, emails transaccionales, SEO y CMS  
**Fecha:** julio 2026  
**Estado:** propuesta para aprobación antes de implementación

---

## 1. Resumen ejecutivo

La guía de marca redefine a Capital Urbano como una desarrolladora **técnica, institucional y orientada a permanencia**, no como una marca genérica de “lujo” o “amenidades”. El sitio actual ya comparte piezas clave (Montserrat, naranja `#FF9933`, negro `#000000`), pero **no aplica el sistema completo**: tipografía secundaria, escala cromática oficial, patrón urbano, jerarquía verbal ni los mensajes rector (tagline, slogan, concepto *Permanencia Urbana*).

Esta propuesta define **qué cambiar, en qué orden y con qué criterios de éxito**, para alinear producto digital + contenido con el PDF sin romper lo ya construido (CMS, admin, API, SEO).

### Objetivo

> Transformar capital-urbano (web + admin + comunicaciones) en una expresión digital fiel a la guía: **método, calidad verificable, permanencia urbana y valor patrimonial**.

### Resultado esperado

| Dimensión | Hoy | Objetivo |
|-----------|-----|----------|
| Mensaje hero | “Descubre tu hogar ideal” / “premium / lujo” | Tagline + slogan oficiales |
| Voz | Marketing aspiracional | Precisión técnica + claridad humana |
| Color | 2 colores + grises ad hoc | Sistema oficial + neutros derivados |
| Tipografía | Montserrat en títulos, **Inter en body** | Montserrat + **Josefin Sans** |
| Identidad visual | Grid genérico, `logo.png` provisional | Logo aprobado + patrón urbano + área de protección |
| Dominio visible | `capitalurbano.com` (config) | Confirmar `capitalurbanomx.com` vs producción |

## 2. Lectura profunda del PDF (síntesis por capítulo)

### 01 — Punto de partida / Estrategia de comunicación

**Idea rectora:** Capital Urbano no debe venderse como desarrolladora genérica (diseño + ubicación + amenidades). El discurso debe anclarse en:

1. **Método** — planeación técnica, control de procesos, decisiones con criterio real.  
2. **Permanencia** — arquitectura y operación pensadas para conservar valor y funcionalidad.  
3. **Calidad verificable** — protocolos, inspecciones, decisiones técnicas en cada etapa.

**Implicación web:** cada página debe responder “¿cómo demostramos método, permanencia y calidad?” — no solo “¿qué vendemos?”.

---

### 02 — ADN de comunicación (5 atributos)

| # | Atributo | Definición (PDF) |
|---|----------|------------------|
| 1 | Método | Procesos claros, decisiones fundamentadas, metodología técnica desde el origen |
| 2 | Calidad verificable | Protocolos, inspecciones, proveedores confiables |
| 3 | Permanencia | Funcionalidad, valor y vigencia a largo plazo |
| 4 | Operación | Proyectos listos para funcionar después de la entrega y administrarse |
| 5 | Calidad integral | BIM, garantías, posventa (el PDF repite “calidad”; en digital unificar en pilares sin duplicar) |

**Pilar visual sugerido para home:** 4 bloques (Método · Calidad verificable · Permanencia · Operación) en lugar de copy genérico de “excelencia internacional”.

## 3. Auditoría del codebase actual (gap analysis)

### 3.1 Lo que ya está alineado

- `cu-orange: #FF9933` y `cu-black: #000000` en `tailwind.config.ts`  
- Montserrat en headings (`global.css`) y amplio uso de `font-montserrat`  
- Josefin cargada en Google Fonts import pero **casi sin uso**

- Admin y emails usan negro + naranja coherente  
- Estructura de páginas (Nosotros, Calidad, Experiencia, Proyectos) compatible con narrativa del PDF

### 3.2 Desalineaciones críticas

#### Mensaje y voz

| Ubicación | Copy actual | Problema vs PDF |
|-----------|-------------|-----------------|
| `Index.tsx` hero | “Descubre tu hogar ideal”, “Arquitectura Premium en GDL” | Genérico; no tagline/slogan |
| `Index.tsx` | “lujo”, “exclusivas”, “exclusivos” | Prohibido por voz de marca |
| `seo.ts` / `index.html` | “premium”, “alta calidad” repetido | Falta permanencia / método |
| CMS `about_hero_subtitle` | “Desarrolladora vertical premium…” | No usa tagline |
| `Projects.tsx` | “desarrollos verticales premium” | Adjetivo vacío |

#### Tipografía

- `body { font-family: Inter }` — **no está en la guía**  
- Josefin Sans sin escala tipográfica definida (tamaños, line-height, letter-spacing)

#### Color y UI

- Hover `orange-600` (Tailwind default) desvía del Carrot Orange  
- Grises `cu-concrete` / `cu-stone` no documentados en PDF (aceptables como neutros UI si se derivan del black scale)  
- `rounded-sm` / `rounded-lg` mezclados — PDF sugiere geometría más arquitectónica (bordes mínimos: OK mantener `radius: 0` en design tokens)

#### Identidad

- Logo provisional; sin isotipo separado ni área de protección en componente  
- Sin patrón urbano asset  
- Hero video/copy no refleja “Permanencia Urbana”

#### Admin y emails

- `_admin_emails.php` usa Helvetica/Arial — debería Montserrat + Josefin (inline safe fonts)  
- Login: “Desarrolladora vertical premium” — actualizar a slogan/tagline

## 4. Propuesta de design system digital

### 4.1 Tokens (archivo único)

Crear `client/lib/brand/tokens.ts` (y espejo CSS en `:root`):

```ts
export const brand = {
  color: {
    orange: "#FF9933",
    black: "#000000",
    orangeScale: { 100: "#FF9933", 80: "#FFAD5C", 60: "#FFC285", 40: "#FFD6AD", 20: "#FFEBD6" },
    blackScale: { 100: "#000000", 80: "#333333", 60: "#666666", 40: "#999999", 20: "#CCCCCC" },
    surface: { warm: "#F5F5F0", white: "#FFFFFF" },
  },
  font: {
    display: "Montserrat, sans-serif",
    body: "Josefin Sans, sans-serif",
  },
  copy: {
    tagline: "Desarrollamos permanencia urbana",
    slogan: "Construimos valor que permanece.",
    valueMantra: "Construimos hoy, generamos valor siempre.",
    concept: "Permanencia Urbana",
  },
} as const;
```

### 4.2 Escala tipográfica

| Token | Font | Size (desktop) | Peso | Uso |
|-------|------|----------------|------|-----|
| `display-xl` | Montserrat | 4.5–6rem | Bold | Hero slogan |
| `display-lg` | Montserrat | 2.5–3rem | Bold | H1 páginas |
| `heading-md` | Montserrat | 1.5–2rem | SemiBold | H2 |
| `heading-sm` | Montserrat | 1.125rem | SemiBold | H3, labels nav |
| `body-lg` | Josefin | 1.125rem | Regular | Lead paragraphs |
| `body-md` | Josefin | 1rem | Regular | Body default |
| `body-sm` | Josefin | 0.875rem | Regular | Metadata |
| `accent-caps` | Montserrat | 0.75rem | SemiBold | Eyebrows (tracking widest) |
| `quote` | Josefin | 1.25rem | Light | Citas institucionales |
